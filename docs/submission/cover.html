1Five-minute review path

  1. See a verdict changeOpen the Gmail guide and toggle Your situation. Internal-only goes from Review required to Instant. Hover any citation number for the exact quote and source.
  2. Ask the guide"Can I avoid Google review?" The answer cites only this guide's verified evidence, and Apply sets your situation for you.
  3. Generate a new guide liveOn the home page, type an app we never researched (Zoom, Dropbox, Asana). It takes about a minute on free models.

4Key decisions

A verification process, not a promptAnswers from memory were wrong or stale (Spotify's user cap, GitHub's token default, the difficulty tiers). Checking against live docs is the product.
No pretend automationAgents can't create OAuth apps: all 5 consoles stopped at sign-in. So the agent probes, researches and drafts, and hands off cleanly.
Code verifies, models writeSearch, the probe, quote checks, labels and tier rules are deterministic. The LLM only extracts and writes, and its output is schema-validated.
Bring-your-own first, free models onlyGuides always cover registering your own app. Runtime uses free OpenRouter models behind a server allow-list; Claude Code was used to build and test only.

7Limitations

Anything behind a console login is unverified and marked UNCERTAIN. Generated guides take about 1–1.5 minutes, and their permalinks can expire on a cold start; curated guides are permanent. Production has no headless browser, so docs that render only with JavaScript may be UNCERTAIN there. Free models sometimes miss numeric caps. A production stream once went silent while the run continued; the page now recovers via a run-status check. Full detail is in the README and VERIFICATION.md.
