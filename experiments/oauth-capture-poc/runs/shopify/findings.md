# Shopify capture findings (public mode, run by a subagent)

- **Captured:** the console wall (1 redirect from `dev.shopify.com/dashboard` to `accounts.shopify.com/lookup`, no bot check, no cookie banner), 7 cropped docs screenshots (8 in total), and 14 of 14 quotes verified on the live pages. Page text for 6 docs pages is saved as `docs-*.txt`.
- **Stopped at:** sign-in. The real Dev Dashboard form was never seen, so the position of the redirect URL field, and where distribution is chosen, are UNCERTAIN.
- **Human must:** sign in, create the app, type the version fields and redirect URL, choose the distribution method, copy the client ID and secret into Composio, and (for public distribution) submit for app review and wait.
- **Surprises and flaky bits:** both docs URLs in `apps.json` redirected to differently named pages. The authorization-code-grant page and the checklist page do not explain app creation or the redirect URL setting; I pulled those from the Dev Dashboard create-app page and the CLI app-configuration reference. The per-shop authorize URL appears in a code block that the screenshot crop truncates, so its full text is only in the saved page text. The linked "redirection URLs" rules page was not captured, so redirect URL rules (HTTPS, localhost, wildcards, limits) are unverified.
- **Time:** about 4 minutes of tool time (214 seconds measured from the first call to the last shot, plus quote checks and writing).
- **Verdict:** moderately useful. The docs captures give the shape of the process and the key Shopify-specific rules (exact-match redirect, per-shop authorize host, review for public apps, immediate OAuth). But the Dev Dashboard form itself is behind an account, so the exact field layout still needs a signed-in human or the logged-in handoff mode. Public mode alone cannot say how long review takes.
