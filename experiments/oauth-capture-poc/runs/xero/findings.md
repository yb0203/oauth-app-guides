# Xero capture findings

- **Captured:** the console wall (1 redirect from `developer.xero.com/app/manage` to `login.xero.com`, email and password only, no bot check, no cookie banner on the login page), 5 docs screenshots (app-type comparison table, create-app and redirect URI rules, uncertified app limits, the Custom Connection create-app dialog image), and 20 of 20 quotes verified on the live pages. 6 screenshots kept, from 8 shot runs (2 retakes).
- **Stopped at:** login. The real My Apps list, New app dialog, redirect URI field and secret button were never seen.
- **Human must:** log in (or sign up) to Xero, accept the developer terms, submit the form, generate the client secret, paste ID and secret into Composio.
- **Xero specifics found:** three app types by grant type (Auth Code, Auth Code with PKCE, Custom connection). Redirect URIs must be https, localhost allowed for testing, 127.0.0.1 and custom URL schemes not allowed. Starter Tier is 5 connections, Core up to 50. Each organisation or practice can connect at most five uncertified apps, with no limit for certified ones. Custom Connections are one organisation, paid monthly, not Marketplace-eligible, and do not count toward the five-app limit.
- **Flaky or awkward:** Xero's docs are server-rendered enough for `text` (5k to 14k characters per page), so no JavaScript problem. A fixed cookie banner overlays the docs screenshots and cannot be dismissed read-only; I picked `--find` strings that keep the key rows clear of it, but the overlay still hides some surrounding text. The create-app dialog exists only as an image in the Custom Connections docs and is stale (25 organisations vs the current text's 5), so the field list is a docs picture, not the live form. I also read the PKCE, Custom Connections and OAuth overview pages (same host as the two in `apps.json`) to cover app types.
- **Not checked:** where the redirect URI field lives in the portal, whether the portal restricts scopes, how a developer creates a Demo Company, and the portal's live labels for the integration types.
- **Time:** about 5 minutes of tool time.
- **Verdict:** good fit for Xero. The limits and rules that matter for Composio users (5 connections, 5 uncertified apps per organisation, https-only redirect URIs, offline_access) all sit in public docs and could be verified verbatim. What a reader still lacks is a picture of the real form, which needs a signed-in human.
